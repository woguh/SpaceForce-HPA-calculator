## Features
- Lightweight
- Copy Results
- Installation selection and altitude adjustments
- Individual event scores and performance breakdowns
- Interactive, responsive dashboard

## Open Source
This project is open source and welcomes community contributions. You can fork the repository, update scoring tables as standards change, customize features, or submit pull requests with improvements and corrections.

## Disclaimer
This is an independently developed project and is not an official U.S. Space Force or Department of Defense website. Always verify results against current official standards.
