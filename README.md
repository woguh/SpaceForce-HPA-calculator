## Features
- Lightweight
- Copy Results
- Installation selection and altitude adjustments
- Individual event scores and performance breakdowns
- Interactive, responsive dashboard

## Open Source
This project is open source and welcomes community contributions. You can fork the repository, update scoring tables as standards change, customize features, or submit pull requests with improvements and corrections.

The Earth texture in the 3D preview uses [Blue Marble: Next Generation](https://science.nasa.gov/earth/earth-observatory/blue-marble-next-generation/), courtesy of NASA Earth Observatory. The cloud, night lights, lunar surface and Milky Way layers adapt [textures by Solar System Scope](https://www.solarsystemscope.com/textures/) under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). These maps were optimized as WebP images. The star field was exposure-adjusted and the cloud map converted to grayscale.

## Disclaimer
This is an independently developed project and is not an official U.S. Space Force or Department of Defense website. Always verify results against current official standards.

The desktop preview uses adapted NASA 3D Resources models of Dawn, Chandra, the Lunar Reconnaissance Orbiter, Bennu, Toutatis, and Kleopatra. The spacecraft textures and mesh detail were optimized for browser rendering. Positions and distances are artistic. [NASA 3D Resources](https://github.com/nasa/NASA-3D-Resources)
